# PIV 装置搭建与实验流程

## 本实验使用的 PIV 技术

PIV 的核心思想是：向流体中加入示踪粒子，用激光片光照亮测量平面，相机连续拍摄粒子运动，再通过相邻帧图像相关计算得到二维速度场。

本项目中，PIV 的作用不是只生成可视化图片，而是提供机器学习模型的真实流场输入。

## 装置组成

| 模块 | 作用 | 本实验关注点 |
|---|---|---|
| 水槽 | 提供近似稳定来流 | 水槽尺寸约长 85 cm、宽 40 cm、水深/高度方向约 35 cm |
| 试样 | 产生不同尾流 | circle、triangle、airfoil、diamond、bar，等面积约 5000 mm2 |
| 水泵/流量调节 | 控制来流速度 | 速度档 5/10/15，按线性近似映射为 Re≈880/1760/2640 |
| 示踪粒子 | 跟随水流运动 | 粒子图像用于互相关计算速度场 |
| 激光片光 | 照亮二维测量平面 | 形成近似二维截面，便于 PIV 测量 |
| 相机 | 采集粒子图像序列 | 分辨率 1920×1080，本轮一次拍摄一个 ROI |
| PIV 软件 | 由粒子图计算速度场 | 导出 CSV，用于后续训练/验证 |

## 试样放置

试样放在水槽中线附近，使来流方向经过试样后产生下游尾流。实验中宽度方向不作为主要建模维度，近似处理为二维流体问题。

推荐展示说法：

```text
我们将试样放置在水槽中部，使来流绕过试样后在下游形成尾流。相机对准试样后方的局部 ROI，重点记录尾流发展区域，而不是完整水槽。
```

## 相机 ROI

相机分辨率为 1920×1080，但一次只能拍一个 ROI。本实验重点关心试样下游的尾流区域：

1. ROI 不需要完整覆盖整个水槽。
2. ROI 应优先覆盖试样后方速度亏损区和剪切层。
3. 如果需要训练模型，ROI 的位置应尽量在不同试样之间保持一致。
4. 如果能看到试样边缘，有助于定位；但模型训练时更关注下游尾流 crop。

本次导出的 PIV 网格约为：

```text
57 × 31 vectors
x = 4.15 - 244.04 mm
y = 7.40 - 135.91 mm
```

这说明真实 PIV ROI 比原始水槽小得多，更像是局部尾流窗口。

## 帧率和采样

实验设备支持约 100 到 1000 fps。本轮处理数据按 100 fps 写入元数据。对于当前速度档，100 fps 已经能得到连续尾流速度场，并且存储压力较低。

PPT 中可以这样解释：

```text
我们没有只保存粒子视频，而是导出每一帧计算得到的速度场 CSV。随后从每条独立实验序列中抽取间隔帧构建 wake-field 数据集，避免相邻帧高度重复导致虚高评估。
```

## 导出的 PIV 字段

PIV 软件可以导出很多图像和张量。对本项目最重要的是速度场 CSV，而不是渲染图。

必须保留：

| 字段 | 用途 |
|---|---|
| X(mm), Y(mm) | 网格坐标 |
| Velocity U(mm/s) | 水平方向速度 |
| Velocity V(mm/s) | 竖直方向速度 |
| Velocity \|V\|(mm/s) | 速度大小 |
| Correlation Value | PIV 相关质量控制 |
| Peak Ratio | 质量控制 |
| Flag | 异常向量标记 |

模型最终使用的 4 个通道为：

```text
ux, uy, speed, vorticity
```

其中涡量由速度梯度计算得到，用来表征旋转和剪切结构。

## 从 PIV 到模型输入

数据流如下：

```text
粒子图像序列
-> PIV 软件互相关
-> 速度场 CSV
-> 规则网格 wake_field.npz
-> 多尺度尾流 crop
-> JEPA 分类模型
```

本实验的训练/测试划分：

```text
seq1 + seq2 用于训练
seq3 用于测试
```

这样可以避免把同一条实验序列的相邻帧同时放进训练集和测试集，减少数据泄漏。

## 线性 Re 近似

现场认为水泵档位和流量近似线性：

```text
45 档约等于 50 m3/h
```

结合水深 35 cm 和水槽宽度 40 cm，当前三个速度档近似为：

| 速度档 | 近似 Re |
|---:|---:|
| 5 | 880 |
| 10 | 1760 |
| 15 | 2640 |

这部分可作为流体力学参数设计展示，说明模型不是只做图像分类，也考虑了来流条件。

## 课程展示可强调的技术收获

1. 搭建了 PIV 测速流程，从粒子图像得到二维速度场。
2. 学会选择相机 ROI，围绕尾流发展区域采集数据。
3. 将实验数据从 CSV 转为机器学习可用的多通道流场张量。
4. 用独立实验序列做训练/测试切分，避免相邻帧泄漏。
5. 将流体力学参数 Re 与机器学习数据集元数据统一。
